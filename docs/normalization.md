# Markdown の読み書きで許容した正規化

`serialize(parse(md))` が元の `md` と一致しない場合のうち、直さずに許容したものを記録する。
現行ルール（`test/fixtures/rules/`、23ファイル）はすべて正規化なしで一致する。

| 正規化 | 内容 | 理由 |
| --- | --- | --- |
| 改行コード | CRLF・CR は LF にそろえる | リポジトリ上のファイルはすべて LF。Windows でチェックアウトしたときに CRLF になることがある |
| 条・前文・附則の中の空行 | 本文の途中にある空行は詰め、警告を出す | 現行ルールに例がない。portal でも空行は段落の区切りになるだけで表示は変わらない |

## 内部モデルに足したもの（手順書の型からの追加）

往復で元と一致させるために、手順書 1-2 の型に次を足した（`packages/core/src/model/types.ts`）。

| 追加 | 現行での例 |
| --- | --- |
| `Division.sep`：「第5章」と見出しの間の空白（既定は半角） | R0701001 `## 第5章　裁判所`（全角） |
| `Article.num` が `null` の条（見出しだけの条） | R0501002 `##### （瑠莉学術公国の旧ボーダー外領土の容認）` |
| 項・号・細分の `cont`：番号のない続きの行（原文のまま） | R0401002 第1条（項の後に国名を並べた行） |
| `Supplementary.provisions`：附則の中の `#####` 見出し | R0701001 `##### 施行附則（…）`・`##### 改正附則（…）`、R0501001 の附則の条 |
| `Appendix`：別表（`## 別表…`） | R0501001 `## 別表第一（第四十一条関係）` |
| リンクの `title` | `[…](R0701002.html#第8条（窃盗の禁止） "現：…")` |
| `RuleMeta.format`：front matter のキー順・引用符・自動生成と異なる値 | 過去の版（`_rule_versions/`）は値を `"…"` で囲み、`title` などが自動生成と異なる |
| `RuleMeta.order` が `null` | 過去の版には `order` がない |

## portal での表示の確認

- 削除した条（`##### 第5条　削除`、本文なし）：portal は kramdown の自動 ID を止め（`_config.yml` の `auto_ids: false`）、目次スクリプトが見出しの文言の空白（全角を含む）を `-` にして ID を付ける。ID は `第5条-削除` になり、本文のない条として表示される。表示・目次は崩れない。ただし削除前の見出しへのリンク（`#第5条（…）`）は切れるため、参照の確認（Phase 7）で扱う。
